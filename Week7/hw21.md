- Encryption vs Hashing vs Encoding
  Encryption protects confidential data. It is reversible using a secret key.

  Hashing converts data into a fixed-length value. It is one-way and cannot be reversed. Password storage should always use a password hashing algorithm like BCrypt rather than encryption.

  Encoding simply converts data into another format. It is completely reversible. Encoding provides no security.

- Authentication vs Authorization
  Authentication answers: Who are you? It verifies a user's identity.Examples include: username/password, Google login, GitHub login, MFA

  Authorization answers:What are you allowed to do? Once the user is authenticated, the system determines their permissions.

  Authentication happens first.
  Authorization happens afterward.

- HTTPS, certificates, key rotation

  HTTP encrypts request and response data. HTTPS uses TLS to encrypt communication between client and server.

  Certificate and keys should be rotated periodically. 
  
- JWT token structure (header, payload, signature)

  Header contains metadata such as token type, signing algorithm.

  Payload contains user-related claims such as username, role, issued time, expiration time.

  Signature is used to verify the token has not been tampered with.

- OAuth 2.0 and OIDC

  OAuth2 allows users to log in through third-party providers such as Google, Github etc.

  OIDC stands for OpenID connecct. Built on top of OAuth2. OIDC can return an identity token that allows multiple services to verify the user identity. 

- LDAP

  Stores all user records, passwords, and permissions in one place. Applications connect to the LDAP server to verify credentials, enabling SSO capabilities.

- SQL injection and prepared statements

  SQL injection happens when user input is directly concatenated into SQL statements.

  Use prepared statements to avoid sql injection. In Spring Boot, JPA/Hibernate usually handles prepared statements automatically. If using JDBC, always use PreparedStatement.
